# Maximum Occupancy

This project contains a simple Python function to calculate the maximum number of concurrent bookings and the time interval when this maximum occupancy occurs.

## Requirements

- Python 3.10 or higher

No external dependencies are required.

## How to run

Clone the repository and open a terminal in the project folder.

Run the application with:

- python main.py

The application includes some example bookings and prints the calculated maximum occupancy for each case.

Example:

- max_occupancy([(9, 12), (10, 13), (11, 14)])

Expected result:

- (3, 11, 12)

## Run tests

To execute the tests, run:

- python -m unittest
